# ACPS-HUB BOOKSHELF

A static website that searches free and legal book sources in one place:
Project Gutenberg, Open Library, the Internet Archive and Google Books.

Developed by Allan. Building smart solutions for better communities through technology and innovation.

## Run locally
Open `index.html` in a browser, or run `python3 -m http.server` and visit http://localhost:8000.

## Deploy with GitHub Pages
Push to GitHub, then go to Settings > Pages and choose the `main` branch, root folder.

## Structure
- `index.html` page markup
- `css/style.css` styles
- `js/app.js` source search logic (one function per source in `sources`)
